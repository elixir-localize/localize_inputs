    Localize.Inputs.Locale (Localize.Inputs v0.1.0)

    View Source

    Locale-derived display data for number form inputs.

    Returns the decimal/grouping separator characters, the native digit system, and the locale's minus sign — everything a JS hook needs to render a number in the user's locale.

    resolve(locale \\ nil, options \\ [])

    @spec resolve(atom() | String.t() | nil, Keyword.t()) ::
  {:ok, t()} | {:error, Exception.t()}

    Resolves display data (separators, digit system, minus sign) for a locale.

    Arguments

    • locale is a locale identifier (atom, string, or Localize.LanguageTag.t/0). Defaults to Localize.get_locale/0.

    • options is reserved for future expansion. Unused today.

    Returns

    • {:ok, t()} carrying the locale's display data.

    • {:error, Exception.t()} when the locale can't be resolved.

    Examples

    iex> {:ok, info} = Localize.Inputs.Locale.resolve(:en)
iex> info.decimal
"."

iex> {:ok, info} = Localize.Inputs.Locale.resolve(:de)
iex> {info.decimal, info.group}
{",", "."}
