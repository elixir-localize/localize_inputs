    Localize.Inputs.Visualizer.Standalone (Localize.Inputs v0.1.0)

    View Source

    Runs Localize.Inputs.Visualizer as a standalone Bandit web server for local development.

    Localize.Inputs.Visualizer.Standalone.start(port: 4003)
# Visit http://localhost:4003

    Enable flag

    Refuses to start unless the visualizer has been enabled:

    config :localize_inputs, visualizer: true

    or pass enabled: true to start/1 explicitly.

    enabled?(options \\ [])

    @spec enabled?(keyword()) :: boolean()

    Returns whether the visualizer is currently enabled.

    Arguments

    • options is a keyword list of options.

    Options

    • :enabled — pass true to force-enable regardless of application config.

    Returns

    • true when either the application env flag or the option is set.

    • false otherwise.

    Examples

    iex> Localize.Inputs.Visualizer.Standalone.enabled?(enabled: true)

    start(options \\ [])

    @spec start(keyword()) :: {:ok, pid()} | {:error, term()}

    Starts the visualizer as a standalone Bandit web server.

    Arguments

    • options is a keyword list of options.

    Options

    • :port — TCP port. Defaults to 4003.

    • :ip — bind address. :loopback (default), :any, or a {a, b, c, d} IPv4 tuple.

    • :enabled — pass true to override the application-level enable flag.

    Returns

    • {:ok, pid()} when the server starts.

    • {:error, :visualizer_disabled} when the enable flag is not set.

    • {:error, term()} propagated from Bandit.start_link/1.

    Examples

    iex> Localize.Inputs.Visualizer.Standalone.start(enabled: false)
{:error, :visualizer_disabled}

    stop(pid)

    @spec stop(pid()) :: :ok

    Stops a previously-started visualizer.

    Arguments

    • pid is the pid returned from start/1.

    Returns

    • :ok once the supervisor has shut down.
