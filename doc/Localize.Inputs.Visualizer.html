    Localize.Inputs.Visualizer (Localize.Inputs v0.1.0)

    View Source

    A web-based visualizer for Localize.Inputs.

    Plug.Router that can be mounted inside a Phoenix or Plug application, or run standalone during development via Localize.Inputs.Visualizer.Standalone.

    Views

    • /input — interactive number input demo.
    • /parse — cross-locale parsing table.
    • /format — cross-locale formatting table.
    • /locale — locale display data table.

    Enable flag

    Localize.Inputs.Visualizer.Standalone.start/1 refuses to boot unless :localize_inputs, :visualizer is set to true in config (or enabled: true is passed explicitly). Mounting under forward/2 in a Phoenix router is not gated.
